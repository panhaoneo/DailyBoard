# A股市场日报生成器

每日自动生成A股市场统计报告，输出Markdown和HTML格式。

## 功能特性

- **数据源**: 新浪财经（实时行情+年K线）、腾讯财经（指数行情）、新浪财经（指数历史K线）
- **统计指标**:
  - A股总数、上涨/下跌/平盘数量及比例
  - 涨幅区间分布（>10%, 5%-10%, 0%-5%, -5%-0%, -10%~-5%, <-10%）
  - 算术平均涨幅、中位数涨幅
  - 当天创年内新高/新低、历史新高/新低的股票列表（排除北交所，使用年K线数据判断）
  - 主要指数表现（今年/本月/本周/当天涨幅、BIAS25乖离率）
- **输出格式**: 统一表格（Markdown + HTML），格式参照原图

## 快速开始

### 1. 安装依赖

```bash
pip3 install requests
```

### 2. 运行程序

```bash
# 获取实时数据并生成报告
python3 main.py

# 使用示例数据生成报告（演示用）
python3 main.py --sample

# 使用缓存数据重新生成报告
python3 main.py --no-fetch
```

### 3. 查看报告

报告生成在 `output/` 目录：
- `latest_report.md` - 最新Markdown报告
- `latest_report.html` - 最新HTML报告（可用浏览器打开）

## 数据源说明

本项目参考 [a-stock-data](https://github.com/simonlin1212/a-stock-data/) 项目的数据源优先级策略：

| 优先级 | 数据源 | 用途 | 风控 |
|--------|--------|------|------|
| 1 | 新浪财经 | A股列表+实时行情 | 低（频繁请求会临时封IP 5-60分钟） |
| 2 | 新浪财经 | 股票年K线数据（年内高低） | 低 |
| 3 | 腾讯财经 | 指数实时行情 | 不封IP |
| 4 | 新浪财经 | 指数历史K线数据 | 低 |
| 5 | 东方财富 | 备用数据源 | 中（有风控，已内置限流） |

**注意**: 频繁请求可能导致IP被临时封禁，等待5-60分钟会自动解封。

## 常见问题

### Q: 运行时报错"Connection aborted"或"拒绝访问"？

A: 数据源API临时封禁了IP，等待5-60分钟后会自动解封。也可使用 `--no-fetch` 参数使用缓存数据。

### Q: 首次运行时间较长？

A: 程序需要获取每只股票今年以来的日K线数据（约250条/只），用于计算年内最高/最低价。约5000+只股票逐个获取，首次预计耗时约5-10分钟。程序支持**增量更新**：当天已更新的股票会缓存，再次运行时直接跳过，耗时仅几秒。跨日运行时会增量获取新数据并与缓存合并。后续可使用 `--no-fetch` 使用缓存数据。

### Q: 创新高/新低股票的数据来源？

A: 使用新浪日K线API获取今年以来的K线数据，计算年内最高/最低价。判断标准：
- **年内新高**: 当日最高价 >= 年内最高价
- **年内新低**: 当日最低价 <= 年内最低价
- **历史新高/新低**: 与年内相同（因为只有今年K线数据）
北交所股票（代码以4、8或bj开头）被排除。

### Q: 如何添加更多指数？

A: 编辑 `config.py` 中的 `INDICES` 列表，添加 `(东方财富secid, 名称, 新浪代码)` 元组。

### Q: 报告中的BIAS25显示"-"？

A: BIAS25需要至少25个交易日的数据，如果历史数据不足会显示"-"。
